> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** перенести утверждённый дизайн (дизайн-панель, круг 3 Эмиля + заставка Якуба 2) в настоящие экраны гостевого приложения rega rega — без новых функций бэкенда.

## Global Constraints
- Ветка `app-phase1`, деплой только превью (`git push` + `npx vercel alias set <url> rega-app-preview.vercel.app`). `main` / regarega.co **не трогать**. Репозиторий **публичный** — никаких секретов.
- Цвет = мир: оранжевый `#FF5E1A` (текстом `#D94612`) — только жильё (знак, квартиры, бронь, поездка, CTA брони). Категории гида: еда `#3A4868` сплошная, транспорт `#3A4868` контурная, велнес `#1F8A5B` сплошная, работа `#1F8A5B` контурная, впечатления `#3D5AFE`. Источник — `src/lib/guideCats.ts` (добавить blue для experiences/nightlife если нужно), не дублировать хексы по файлам.
- Логотип 1:1 как на сайте: знак-дырокол (path из `public/favicon.svg`/брендбука, дырка `M 64,64 r=12`) + `rega` + `rega` opacity .36, Bricolage 800, −.04em.
- Шрифты: `"Bricolage Grotesque","Golos Text",sans-serif` (латиница/цифры — Bricolage, кириллица — Golos 800 для заголовков); метки — JetBrains Mono умеренно.
- Без эмодзи. Иконки Tabler (inline SVG). Формы без `prompt()`.
- Движение: только проявление на месте, горизонталь, дуга, масштаб, кроссфейд. Никогда падение сверху/удар/вспышка/осколки/тряска. `prefers-reduced-motion` → без движения. Анимировать только transform/opacity/filter.
- Тексты RU на «ты», строчные заголовки, голос: «спроси у местного», «мы сами ходим сюда», «пробито нами». EN-версия везде, где сейчас есть EN-маршрут.
- Ежедневной заставки НЕТ. Заставка + знакомство — только при первом запуске (localStorage `rr_onboarded`), тап — пропустить.

## Review Focus
1. Гость без брони / с бронью (`html.has-trip`): вкладка «жильё» ↔ «поездка» должна переключаться как сейчас.
2. Узкий экран (iPhone SE 375×667) и большой (430×932): ничего не обрезается, стеклянное меню не перекрывает последние кнопки (отступ снизу под safe-area).
3. Русский и английский: длинные русские слова в огромных заголовках не вылезают за экран (перенос/уменьшение).
4. Экраны без сети / ошибка API (бронь, консьерж, профиль): существующие состояния ошибок сохранены и выглядят в новом стиле.
5. Первый запуск: заставка и знакомство показываются один раз; повторное открытие — сразу гид; переход по прямой ссылке (поездка по токену, push → поездка) знакомство НЕ перехватывает.
